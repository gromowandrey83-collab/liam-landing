# Liam Cooper: лендинг-история

История Лиама (React + Vite + Tailwind): биография, фотографии и форма с именем и телефоном.
Тексты и ссылка формы — в начале `src/App.tsx` (`STORY`, `FORM_ENDPOINT`). Фото лежат в `public/photos/`.

## Проверить на своём компьютере
1. Установите Node.js LTS (nodejs.org).
2. В папке проекта: `npm install`, затем `npm run dev`.
3. Откройте адрес из терминала (обычно http://localhost:5173). С телефона в той же сети Wi-Fi откройте адрес «Network», который покажет терминал.

## Опубликовать на GitHub Pages
1. Создайте на github.com новый публичный репозиторий (бесплатный Pages работает для публичных).
2. Загрузите в него все файлы проекта (папка `.github` обязательна) и убедитесь, что ветка называется `main`.
3. Repository → Settings → Pages → Build and deployment → Source: **GitHub Actions**.
4. Откройте вкладку Actions и дождитесь зелёной галочки (1–2 минуты).
5. Сайт будет по адресу `https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`.

## Форма
Чтобы заявки приходили, создайте форму на formspree.io (или аналоге), скопируйте адрес вида `https://formspree.io/f/xxxx` и вставьте в `FORM_ENDPOINT`. Пока адрес пуст, форма честно сообщает, что не подключена.
